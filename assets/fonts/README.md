# 思源黑体

应用内置 Adobe Source Han Sans 2.005 的简体中文可变字体，不依赖网络或系统安装。

- 文件：`source-han-sans-cn-vf.woff2`
- 字重范围：250–900
- 上游文件：[SourceHanSansCN-VF.otf.woff2](https://github.com/adobe-fonts/source-han-sans/blob/2.005R/Variable/WOFF2/OTF/Subset/SourceHanSansCN-VF.otf.woff2)
- 许可：SIL Open Font License 1.1，完整文本见 [OFL.txt](OFL.txt)

字体文件按上游原样保留。

使用官方 CN 区域版本，兼容当前 Electron 对 WOFF2 解压大小的限制。
