# NoNotebook

超级简笔记本。

本地、纯文本。目录是章节，纸页是纸张，打开后铺在同一张桌面上。可以随手记几句话，也可以把一个主题的内容放在一起慢慢整理。

## 开始使用

需要 Node.js 和 npm。

```sh
git clone https://github.com/yankening/NoNotebook.git
cd NoNotebook
npm ci
npm start
```

目前从源码运行，没有安装包。

## 纸张桌面

用触控板双指滑动移动桌面，捏合缩放。上下、左右和斜向移动都可以，指针停在纸张上时也是同样的操作。

鼠标可以拖动桌面空白处，或按住中键拖动。点击“全局”查看所有纸张，点击缩放百分比恢复到 100%。点击任意纸张就能写字；内容较长时纸张会自动加长，底部的 `+` 也可以手动延长。

返回目录再打开同一章节，会回到刚才的位置。这个位置只保留到本次关闭应用前。

| 操作 | 快捷键 |
| --- | --- |
| 返回目录 / 取消弹窗 | `Esc` |
| 新建纸张 | `Ctrl + N` |
| 定位前一张 / 后一张纸 | `Ctrl + ← / →` |
| 放大 / 缩小 | `Ctrl + + / -` |
| 恢复 100% | `Ctrl + 0` |
| 查看全部纸张 | `Ctrl + Shift + 0` |
| 立即保存 | `Ctrl + S` |

目录底部的 `+` 新建章节。右键章节可以重命名或删除，右键纸张可以删除该页。定位到最后一张纸后继续向后，会新建一张纸。

## 字体

界面和正文使用内置的思源黑体，离线也能加载。标题、正文和提示使用不同字重。字体来源与许可见 [assets/fonts/README.md](assets/fonts/README.md)。

## 保存与备份

停止输入 500 毫秒后自动保存。关闭或刷新窗口前，会先保存刚输入的内容和正在修改的章节名称。保存失败时会取消关闭或刷新，留下当前内容并显示“重试保存”。

笔记保存在 Electron 的用户数据目录。Windows 下通常是：

```text
%APPDATA%\no-notebook\notebook.json
```

同目录下的 `notebook.json.bak` 是上一份有效内容。笔记文件无法读取时，应用会显示提示并保留原文件。

需要从备份恢复时，先退出应用，把现有 `notebook.json` 另存一份，再将 `notebook.json.bak` 复制为 `notebook.json`。

## 开发

没有打包和编译步骤，修改源码后重启应用即可。

- `main.js`：窗口、应用生命周期和进程通信。
- `preload.js`：提供给界面的读取、保存与关闭接口。
- `renderer.js`：章节、编辑器和交互。
- `canvas.js`：桌面平移、缩放的坐标计算。
- `storage.js`：文件校验、保存队列和备份。
- `index.html`、`style.css`：界面结构和样式。

运行检查：

```sh
npm test
npm run test:ui
```

交互测试会启动 Electron，使用临时笔记目录。测试涉及桌面移动、缩放、中文换行、弹窗、保存失败、刷新和关闭前保存。
